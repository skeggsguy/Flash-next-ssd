# Flash-Next SSD guides

Guides for running Qwen3.8-Flash-Next with this fork on an Apple Silicon Mac. Start with the
[project README](../../README.md) for what the fork does and the quick start.

| Guide | Read it when |
|---|---|
| [Getting started](getting-started.md) | You are setting up for the first time: build, download, the optional second drive, the wired-memory limit, and what a healthy start looks like. |
| [Settings](settings.md) | You want to change something: every option for this model, its default, when to change it, and how to set it as a command-line flag, an environment variable or an INI preset. |
| [Memory sizing](memory-sizing.md) | You are choosing the expert cache and context size, on 64 GB or 48 GB, or you saw swap. |
| [The chat window](chat-window.md) | One server is shared between you chatting and a coding agent working in the background. |
| [Results](results.md) | You want the measurements behind the numbers, and how they were taken. |
